# アパート管理アプリ

祖父が管理するアパート（1棟10部屋）の記録を残すためのアプリ。
家賃の計算だけでなく、**「なぜその判断をしたか」という経緯ごと家族に引き継ぐこと**を目的にしている。

- 入居者の名前・家賃・電話番号などの**個人情報は、このリポジトリには一切入っていない**
- データは使う人のスマホの中（IndexedDB）だけに保存され、外部に送信されない
- 費用は0円（GitHub Pages・GitHub Actions の無料枠のみ）

## 中身

| 場所 | 内容 |
|---|---|
| `PLAN.md` | 開発計画 |
| `app/` | アプリ本体（React + TypeScript + Vite） |
| `design/` | デザイン案（A・B・C の3案と比較） |

| `preview-all.html` | 全画面を並べた一覧（JS不要で開ける） |

## 開発

```
cd app
npm install
npm run dev     # 手元で動かす
npm run test    # 日付・金額・家賃の計算、済／未の切替、控えの往復、版上げをテストする
npm run build   # 公開用に固める
```

`main` に送ると GitHub Actions が自動でビルドし、GitHub Pages に公開する。

## 決めごと

- 日付は必ず `'2026-08-25'` の文字列で持つ。`new Date('2026-08-25')` はUTC解釈で日本時間だと1日ずれるため、`src/lib/date.ts` の `parseDate()` を通す
- 金額は整数の円のみ（小数を持たない）
- データは部屋番号ではなく `id`（UUID）で結ぶ。入居者が変わっても過去の記録が読めるようにするため
- 上書きせず履歴として残す：家賃の変更・契約の更新・退去と再入居。消すときは行を削らず `deletedAt` を入れる
- 表を足すときは `src/db.ts` の `version()` を1つ増やし、`SCHEMA_VERSION` も同じ数にそろえる。
  合わせて `src/lib/backup.ts` の `MIGRATIONS` に「前の版 → 新しい版」の手当てを足す（**一度書いたら消さない**）
- 控えJSONに写真は入れない（base64で1.33倍に膨らむ）。写真は別のファイルとして渡す
- 記録する時刻は必ず `src/db.ts` の `now()` を通す（同じミリ秒でも必ず前より後を返すので、履歴の前後が入れかわらない）
- 計算は `src/lib/` に置き、データベースには触らせない。画面はその結果を並べるだけにする
- 文字サイズは `rem` で指定する（端末の文字拡大に追随させるため）
- 押せる場所は最小 64px、補足の文字も 17px を下回らない
- `:active` と `:focus-visible` を、押せる要素すべてに定義する
